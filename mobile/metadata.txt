changelog=
  Version 1.0.4:
  - 💬 原生 Toast 触控全屏反馈：集成 QField 官方 displayToast 浮动提示，消除模态弹窗点击无反应假象，提升外业触控确定性。 / Integrated QField native displayToast floating feedback to eliminate silent tap ambiguities in modal dialogs.
  - 📋 主动焦点剪贴板自愈：点击【粘贴识别】强制输入框获得焦点并读取系统剪贴板，适配不同 Android 版本安全剪贴板策略。 / Active-focus clipboard retrieval fallback ensuring reliable IP parsing across diverse Android privacy policies.

  Version 1.0.3:
  - 📋 扫码自动识别与配对回传：支持手机自带相机扫码后自动嗅探剪贴板回填电脑 IP 与目标工程，秒级配对免除手机小键盘手动输入烦恼。 / Automatic clipboard URL sniffing & pairing from mobile camera QR scanning without manual typing.
  - 🔗 智能探测自愈与工程校验：自动触发局域网连通探测，并校验外业手机工程名是否一致，保障成果精准归档。 / Automatic connectivity probing with project identity verification.

  Version 1.0.2:
  - 🎨 修复选项排版遮挡：重构 RadioButton 单选指示点与文本间距布局，彻底解决移动端回传类型圆点被标题文字覆盖的问题。 / Fixed radio indicator dot being obscured by title text with dedicated coordinate layout and safe gutter.
  - 🔘 优化触摸交互与互斥分组：引入 ButtonGroup 规范单选互斥，支持整行触控切换，指示点与首行文字垂直居中对齐。 / Added ButtonGroup for reliable mutual exclusion and aligned indicator vertically with title.
  - ⚡ 实时热打包：电脑端提供最新的插件下载，规避离线安装包旧版缓存。 / Real-time packaging without stale cache.

  Version 1.0.1:
  - 📦 增量与整包双回传模式：支持外业仅回传修改图层与现场照片（秒级上传），或全量打包回传工程。 / Added Incremental (layers + photos) and Full project return modes.
  - 🔍 电脑端服务连通性探测：支持在手机端一键探测桌面 QGIS 局域网端口连通状态与错误诊断。 / One-click desktop server ping and reachability diagnostics.
  - 📊 传输进度与状态反馈：新增外业成果打包与分块回传实时进度条与状态提示。 / Real-time upload progress bar and status feedback.

  Version 1.0.0:
  - 🚀 初始版本发布：QField 移动端局域网成果回传助手，外业数据无需云端即时交还电脑 QGIS。 / Initial release of QFieldDrop mobile companion plugin.
