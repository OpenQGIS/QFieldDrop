  Version 1.1.4:
  - 🌐 极简下载地址与秒级扫码：下载直链优化为 /project.zip，移除繁琐的中文 URL 转义，大幅降低二维码点阵密度并提升手机扫码识别率；保留 RFC 6266 标准标头确保手机下载后仍自动保存为真实中文工程名。 / Streamlined download URL to clean /project.zip alias, removing percent-encoded Chinese characters to produce lower-density, faster-scanning QR codes while retaining RFC 6266 automatic filename decoding.
  - 🗂️ 扫码投送子 Tab 栏重构：将相机唤醒、浏览器下载与手动离线通道重构为顶部水平子选项卡，界面空间充裕自然，彻底杜绝元素折行挤压。 / Reorganized QR dispatching into 3 top-aligned horizontal sub-tabs for clean layout and improved readability.
  - 📱 手机助手安装器重构：将 QField 伴侣插件安装对话框升级为双 Tab 结构（扫码直装 / ADB 数据线写入），消除白边残留并优化展示排版。 / Reorganized mobile installer into 2 clean tabs with fixed vertical margins and aligned layout.
  - 📁 成果接收路径展示优化：存储目录支持单行智能居中截断（ElidedLabel）与悬停提示，新增紧邻的【打开】按钮并独立关联工程行，排版工整不溢出。 / Enhanced storage path presentation in receive dialog with middle-elided text, hover tooltips, and adjacent open button.
  - 🛡️ 线程生命周期与 QGIS 防崩加固：在所有对话框销毁、关闭及异常退出时全面部署安全断开与优雅退出守护，彻底杜绝 QThread 崩溃。 / Hardened worker thread detachment and safe termination guards to prevent QThread crashes on dialog close.

  Version 1.1.3:
  - 📷 扫码智能回传全链路联动：成果接收二维码升级支持携带当前关联工程名参数（?proj=xxx），手机相机扫码自动嗅探电脑主机并配对目标工程，告别手动输入 IP。 / Upgraded return QR code to carry target project metadata; mobile companion auto-sniffs clipboard to pair and configure desktop host.
  - 📱 移动端伴侣组件升级 (v1.0.3)：同步升级内置的 QFieldDrop Mobile 伴侣插件至 v1.0.3，支持扫码自动识别与唤醒流，自动触发连通探测与工程校验。 / Bundled updated mobile companion v1.0.3 with auto QR sniffing & deep link wake support.
  - 🌐 移动端回传网页体验增强：手机扫码打开的网页新增 [复制并唤醒 QField] 按钮与当前工程名徽标，无需翻找 Android 沙盒。 / Inbound return web page adds direct QField wake button & project badge.

  Version 1.1.2:
  - 📐 侧边抽屉式资源管理：将外部图层诊断与树图整合为向右抽屉，默认保持 520px 紧凑收起，点击平滑展开，收起零留白。 / Collapsible Inspector Drawer for layer distribution & external layer diagnostics; defaults to compact 520px window.
  - ⚡ 毫秒级性能优化：引入内存预热缓存，彻底根除点击展开时主线程扫描磁盘文件的 250ms+ 阻塞，展开耗时降至 38ms。 / Sub-40ms instant drawer toggle backed by pre-cached disk inspection data.
  - 🏷️ 工程名自定义与信息栏瘦身：支持直接修改导出工程名并重新打包，彻底移除包含文件数量冗余文本。 / Editable custom export project name with streamlined top info bar.
  - 📋 成果回收表格右键菜单：支持安全删除本地外业归档、系统文件夹定位、一键载入工程比对与解压。 / Added context menu & Del shortcut to inbound return records for safe deletion and layer inspection.
  - 🤫 全界面文字深度降噪：常驻说明书式长段文字全面升级为轻量微标与鼠标悬停 Tooltip，界面清爽耐看。 / Reduced verbose UI text by 70% using micro-badges and hover tooltips.

  Version 1.1.1:
  - 🚀 全异步防假死架构：将大工程数据 ZIP 压缩移至独立 QThread 后台工作线程，窗口即时弹出并提供文件实时进度条，彻底杜绝 QGIS 界面卡顿未响应。 / Fully non-blocking asynchronous packaging engine with real-time progress bar.
  - ⚡ ADB 通信子线程化：将手机外业成果拉取与插件安装写入改由后台 Worker 执行，规避超时或网络拥堵造成的界面冻结。 / Moved ADB pull and install operations into background threads to eliminate UI blocking.

  - 🔍 LocalSend 直连探测优化：将局域网手动 IP 探测加入后台轻量线程，不可达 IP 探测零掉帧。 / Non-blocking background IP probing for manual LocalSend connection.

  - 📱 手机助手安装器：新增 QField 伴侣插件安装对话框，支持扫码安装、URL唤醒、ADB写入与离线包导出。 / Added mobile companion installer dialog supporting QR install, deep link, ADB push, and offline ZIP.
