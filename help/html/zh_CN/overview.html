🌟 快速认识 QField LAN Drop

专为外业 GIS 打造的轻量级闭环直传工具：出工一键投送（电脑 ➔ 手机） + 收工一键回传（手机 ➔ 电脑）。

100% 局域网离线直连，无需任何云服务器，无需数据线翻找沙盒目录。

🧭 工具栏双动作快捷入口

在 QGIS 顶部工具栏点击对应的专属图标即可直接开始：

[ 📤 投送工程至 QField ]    [ 📥 接收 QField 成果 ]    [ 📱 手机助手 ]
  • [ 📤 投送工程至 QField ]：出工前点击，自动保存打包，手机扫码即走。
  • [ 📥 接收 QField 成果 ]：收工后点击，<0.1秒极速开启接收服务，手机扫码上传成果。
  • [ 📱 手机助手 ]：首次使用时，为手机 QField 安装离线伴侣插件。
