## 🔒 数据安全与存储规范

### 1. `_qfield_return` 时间戳防覆写机制
为保障外业核心成果的绝对安全，插件**绝不直接覆写当前工程的原始文件**：
* 每次接收成果时，系统会自动在工程根目录下生成隔离的快照子目录：
  ```plaintext
  <工程根目录>/_qfield_return/2026-10-28_17-30-00_RedmiK40/
  ```
* 即使多名外业人员在不同时段回传同一个名称的图层，成果也会按时间戳和设备名称整整齐齐分别归档，完全杜绝了误覆盖的风险。

### 2. 临时打包文件的自动清理
* 在出工打包时生成的临时工程 ZIP 文件，在关闭投送窗口或下次重新打包时会自动被清理，不会永久侵占电脑的系统盘空间。

## ⚡ 快捷键速查

| 快捷键 / 动作 | 触发功能 |
| :--- | :--- |
| **Esc** | 快速关闭当前帮助中心或投送/接收窗口 |
| **F5** (在接收窗口) | 刷新局域网待命状态与接收列表 |
| **右键条目** (接收台账) | 弹出「在文件夹中定位」与「加载至当前 QGIS」菜单 |
