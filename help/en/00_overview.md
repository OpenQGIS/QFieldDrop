# 🌟 Overview & Quick Start

A lightweight, full-cycle offline transfer tool for field GIS: **Morning Dispatch (PC ➔ Mobile) + Evening Return (Mobile ➔ PC)**.

100% LAN offline direct connectivity with zero cloud servers and no MTP cable folder hunting.

---

## 🧭 Toolbar Shortcuts

Click the corresponding action on the top QGIS toolbar:

```plaintext
[ 📤 Drop Out (Send to QField) ]    [ 📥 Drop In (Receive from QField) ]    [ 📱 Mobile Setup ]
```

* **[ 📤 Drop Out ]**: Click before heading out. Auto-packages current project and provides instant QR scan.
* **[ 📥 Drop In ]**: Click upon returning. Opens receiving service in <0.1s to receive mobile uploads.
* **[ 📱 Mobile Setup ]**: First-time setup to install the companion plugin onto QField Mobile.
